# Three.js Sunflower Room

Static Three.js hero scene with camera parallax and fluid pointer trails.

## Files

- `index.html`：page entry and Three.js import map
- `main.js`：scene, lights, camera rig, particles and model loading
- `fluid.js`：velocity-field fluid simulation and composite pass
- `web_Mesh.glb.part0` / `.part1`：split GLB, combined in the browser

Three.js and its addons are loaded from the pinned unpkg CDN. The model is
served by GitHub Pages.
